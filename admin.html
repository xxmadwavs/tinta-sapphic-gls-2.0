    Normalizador de valores

    Sustituye valores de campos del catálogo (series, anime, realities y películas) usando únicamente un mapa de equivalencias aprobado. Cargar el mapa solo muestra una vista previa: no cambia nada hasta que confirmes de forma explícita. Los valores que no estén en el mapa se conservan tal cual.

    Formato del mapa y reglas

    Un archivo JSON con este formato (los valores de abajo son solo marcadores de posición, no equivalencias reales):

    {
  "version": 1,
  "aprobado": { "por": "NOMBRE", "fecha": "AAAA-MM-DD" },
  "campos": {
    "country": { "VALOR_ORIGEN": "VALOR_DESTINO" }
  }
}
    • Campos admitidos: .
    • La coincidencia es exacta (mayúsculas, tildes y espacios incluidos). Nada se deduce por parecido: «Netflix» y «Netflix Standard with Ads», o «Paramount+» y «Paramount Plus Premium», solo se unen si el mapa lo dice explícitamente.
    • En country (separador « / ») y network (separador «,») se compara primero el valor completo y, si no coincide, cada elemento por separado; si cambia alguno, el valor se reescribe con el separador estándar (« / » o «, ») y sin elementos repetidos.
    • En los campos de lista se compara cada elemento; si cambia alguno, se eliminan los repetidos que resulten.
    • El destino no puede estar vacío ni tener espacios al inicio o al final, y no puede ser a la vez origen de otra equivalencia (sin cadenas).
    • Sin aprobado.por y aprobado.fecha válidos el mapa se considera sin aprobar: se puede ver la vista previa, pero no aplicar. La herramienta no puede comprobar la aprobación; solo exige que conste en el mapa.
    • No se modifica updatedAt ni ningún otro campo.

    Cómo publicar cambios
    Cada vez que hagas cambios, sigue estos pasos:
    1. Pulsa "Exportar data.json" arriba.
    2. Ve a tu repositorio en github.com.
    3. Haz clic en el archivo data.json y luego en el icono del lápiz
    4. Borra todo el contenido y pega el del archivo descargado.
    5. Pulsa "Commit changes". En segundos tus amig@s verán los cambios.
